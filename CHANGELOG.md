## [1.0.0] - 2026-02-13

### Added
- Menu bar native Pomodoro timer for macOS
- Liquid Glass translucent panel with macOS-native glass effect
- Pomodoro cycle management (Focus → Short Break → Focus → Long Break)
- Global keyboard shortcuts for timer control from anywhere
- 4 built-in presets:
  - Deep Focus (50min focus, 10min break, 30min long break)
  - Standard (25min focus, 5min break, 15min long break)
  - Quick Sprint (15min focus, 3min break, 10min long break)
  - Creative Flow (45min focus, 10min break, 20min long break)
- Visual, audio, and haptic feedback notifications on session completion
- Statistics tracking for daily sessions, focus time, streaks, and weekly/monthly trends
- Data export functionality (CSV and JSON formats)
- Bilingual support (English and Japanese localization)
- Menu bar display levels (Minimal, Standard, Full)
- Settings window with customizable timer preferences
- Onboarding experience for first launch
- Statistics dashboard with charts
- Lightweight performance (< 25MB memory, < 0.1% CPU when collapsed)
